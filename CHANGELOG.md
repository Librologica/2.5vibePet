# Changelog

## 1.0.0 — 2026-10-01

- First public PET4032/32 KB package; automatic and interactive procedural demo.
- Native 6502 DDA, 40 rays, monochrome ROM-character viewport, software back screen.
- White walls, 50% sides, sparse dotted floor and exact half-block boundaries.
- Continuous procedural navigation, collision, lintelled doors, 50 Hz tick source.
- Reproducible build, public numeric/frame tests, bilingual documentation/licenses.
- No audio; no change to the frozen 3Dvibe64 or other platform SDKs.

- Primo pacchetto pubblico PET4032/32 KB, demo procedurale automatica e interattiva.
- DDA 6502 nativo, 40 raggi, viewport monocromatica a caratteri ROM, back screen software.
- Pareti bianche, lati al 50%, pavimento puntinato e contorni a mezzi blocchi esatti.
- Navigazione procedurale continua, collisioni, porte con architrave, tick a 50 Hz.
- Build riproducibile, test pubblici numerici/frame, documentazione e licenze bilingui.
- Nessun audio; nessuna modifica agli SDK congelati 3Dvibe64 o delle altre piattaforme.
