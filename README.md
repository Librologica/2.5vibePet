# 2.5vibePet

Native monochrome 2.5D software raycaster for the Commodore PET 4032, 32 KB.
Standalone derivative of the 3Dvibe64 family. Version 1.0.0.

Raycaster 2.5D monocromatico nativo per Commodore PET 4032, 32 KB.
Derivato autonomo della famiglia 3Dvibe64. Versione 1.0.0.

[Italiano](README.it.md) · [English](README.en.md) · [Quick start](QUICKSTART.md)

Included: automatic and interactive procedural-world PRGs, full host/6502
sources, numeric and emulator tests, bilingual pipeline and assembly manuals.
Inclusi: PRG automatico e interattivo del mondo procedurale, sorgenti host/6502,
test numerici e su emulatore, manuali bilingui della pipeline e dell'assembly.
